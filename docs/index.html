Video Frame Extractor

Bienvenue dans la page GitHub Pages du projet. Ce site présente le projet et explique comment exécuter l'application localement ou depuis un serveur compatible.

Ce que vous pouvez déployer sur GitHub Pages

GitHub Pages ne peut pas exécuter un serveur Python ou OpenCV. Il héberge uniquement du contenu statique (HTML/CSS/JS).

  • Documentation du projet
  • Guide d'installation
  • Présentation des fonctionnalités

Comment utiliser l'application

  • Exécutez le serveur localement : python app_web.py
  • Accédez à http://localhost:5000
  • Sur téléphone, ouvrez l'adresse réseau de votre PC : http://:5000
Voir le code sur GitHub

Déploiement recommandé

  • GitHub Pages : pour la documentation uniquement
  • Replit / PythonAnywhere / Heroku : pour la version web réelle
  • Docker ou VPS : si vous souhaitez exécuter Flask en production

Documentation rapide

  • app.py : application Tkinter locale
  • app_web.py : serveur Flask pour navigateur
  • templates/index.html : interface web mobile
  • docs/index.html : page statique GitHub Pages
Déployez ce dossier docs/ sur GitHub Pages pour un site de présentation et de documentation.
